# Awesome Korean

See [Awesome Korean](https://github.com/mariabnd/awesome-korean) &
[All Language Resources](https://www.alllanguageresources.com/resources/korean).

## Tools

- [Naver Dictionary](https://korean.dict.naver.com/english): the standard Korean-English dictionary, with example sentences and conjugation tables
- [dongsa.net](https://koreanverb.app/): Korean verb conjugation lookup — shows how a conjugation is derived step by step
- [Korean From Seoul verb conjugator](https://koreanfromseoul.com/korean-verb-conjugator/): free interactive conjugation *practice* tool — type the form yourself and get instant feedback, no signup

## Communities

- [r/Korean](https://www.reddit.com/r/Korean/): active learning community with weekly practice threads
- [Korean Language Stack Exchange](https://korean.stackexchange.com/): Q&A on grammar and usage
