# Awesome Kyrgyz

Kyrgyz (кыргыз тили) is a Turkic language of the Kipchak branch, spoken by about 5 million
people, mostly in Kyrgyzstan. It is written in Cyrillic: the 33 Russian letters plus ң, ө
and ү — so if you read Russian, you can read Kyrgyz aloud after one evening. Grammar is
agglutinative with vowel harmony and SOV word order, much like Turkish; vocabulary and
sounds differ enough that Turkish speakers do not understand spoken Kyrgyz.

It is a low-resource language, so the materials are scattered. Everything below is free.

## Courses

- [Peace Corps Kyrgyz course (Live Lingua Project)](https://www.livelingua.com/project/peace-corps/Kyrgyz) — a full course with audio, free PDF and MP3.
- [CeLCAR Kyrgyz language portal (Indiana University)](https://celcar.indiana.edu/materials/language-portal/kyrgyz.html) — academic description and teaching materials.
- [learn.kg](https://learn.kg/en) — an A1/A2 course built around 1000+ phrases with native-speaker audio, spaced repetition and drills. The phrasebook, phrase translator and level test are free without signup.

## Phrases

- [learn.kg phrasebook](https://learn.kg/razgovornik/en) — 337 situational phrases, each with native audio and an English gloss.
- [learn.kg phrase translator](https://learn.kg/perevodchik/en) — search across the course phrase base (not machine translation).
- [Wikivoyage Kyrgyz phrasebook](https://en.wikivoyage.org/wiki/Kyrgyz_phrasebook) — travel basics with transliteration.

## Dictionaries

- [tili.kg](http://tili.kg/dict/) — explanatory and bilingual dictionaries.
- [tamgasoft.kg](http://tamgasoft.kg/dict/) — Kyrgyz–Russian dictionary.
- [Lexilogos: Kyrgyz dictionaries](https://www.lexilogos.com/english/kyrgyz_dictionary.htm) — collected dictionary links.

## Writing system and grammar

- [Omniglot: Kyrgyz](https://www.omniglot.com/writing/kirghiz.htm) — alphabet history (Arabic script → Latin 1928–1940 → Cyrillic since 1940) and pronunciation.
- [A Handbook of Kyrgyz Grammar (Wikibooks)](https://en.wikibooks.org/wiki/A_Handbook_of_Kyrgyz_Grammar/Nouns) — cases, plurals, agglutination.

## Input (listening and reading)

- [Azattyk — RFE/RL Kyrgyz service](https://www.azattyk.org) — news and radio in Kyrgyz.

## Exams

- [Kyrgyztest](https://kyrgyztest.gov.kg/) — the state assessment system, levels A1–C1, with official practice tests. The certificate is required by law for civil servants, and on a phased schedule for teachers and medical staff.
