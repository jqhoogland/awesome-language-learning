# Awesome Farsi

Resources for learning Persian / Farsi.

## Guides

- [All Language Resources: Persian](https://www.alllanguageresources.com/persian-resources/) - Curated Persian learning resources across courses, apps, podcasts, books, and tools.

## Courses

- [Persian Language Online](https://persianlanguageonline.com/) - Free Persian lessons, stories, and graded material from the Iran Heritage Foundation.
- [Chai and Conversation](https://www.chaiandconversation.com/) - Audio lessons focused on conversational Persian and Iranian culture.
- [Easy Persian](https://www.easypersian.com/) - Free structured Persian lessons covering script, grammar, vocabulary, and listening.

## Apps

- 💰 [Learn Farsi: Real Persian](https://learn-persian.pages.dev/?utm_source=awesome_language_learning&utm_medium=organic&utm_campaign=farsi_resources) - Spoken-first Persian lessons for beginners and heritage learners, with romanisation, Persian script, audio, quizzes, handwriting practice, and cultural notes.

## Dictionaries and pronunciation

- [Forvo: Persian](https://forvo.com/languages/fa/) - Native-speaker pronunciation recordings for Persian words.
- [Vajehyab](https://www.vajehyab.com/) - Persian dictionary and lookup tool.
