# Awesome Türkçe (Turkish)

See [All Language Resources](https://www.alllanguageresources.com/resources/turkish).

## 📀 Resources
- [Manisa Turkish](https://www.turkishlanguage.co.uk/): Free reference for Turkish grammar, covering the cases, vowel harmony and the tense system, with exercises.

## 🎓 Courses
- 💰 [TurkishFluent](https://turkishfluent.com/): A1-B2 course with native-speaker dialogues at normal and slowed speed, pronunciation feedback and interactive exercises. The whole A1 level (16 lessons) is free.

## 📚 Dictionaries
- [TDK Sözlük](https://sozluk.gov.tr/): The official dictionary of the Turkish Language Association (Türk Dil Kurumu).
